# Research artifact status

The timestamped files from `2026-08-23` are immutable evidence from the retired CoinMarketCap-signal experiment. They answer a historical question about that third-party series only.

They do **not** validate, backtest, or describe the current repository-owned Crypto Risk Appetite model. The active backtest uses schema v2 and intentionally refuses those schema-v1 input snapshots. New own-model runs create new dated snapshots and result files without overwriting the legacy evidence.
